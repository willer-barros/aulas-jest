# Aulas para aprendizado do jest
O jest é uma ferramenta poderosa para testes unitarios(pequenos blocos de codigo)

### Entendendo as Cores
Vermelho => teste com erro
Amarelo => Atende parcialmente
Verde => Teste aprovado(pass)

### Para Projetos Resi
Ideal buscar 100% do codigo testado
Minimo aceitavel 80%
